A GTA VI trophy guide and tracker covering all 55 official trophies: a searchable checklist with progress saved in your browser, per-trophy guides in the entrant's own words with sources, a spoiler-safe mode that masks story trophies, and a six-stage platinum roadmap with missable warnings.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080.
